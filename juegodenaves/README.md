# Juego de naves

Este repositorio contiene la estructura base del proyecto de la actividad 8 de Programación Orientada a Objetos.

## Estructura

- `src/`: código fuente principal
- `docs/`: documentación e informes
- `capturas/`: evidencias de ejecución

## Compilación

```bash
cd juegodenaves
g++ src/main.cpp -o juego
./juego
```

## Descripción

El proyecto consiste en un juego de naves en consola, con interacción por teclado y lógica de combate.
